# Трекер привычек — установка

Всё бесплатно: Google Таблица + Apps Script как backend, GitHub Pages как хостинг фронтенда,
Firebase Cloud Messaging (по желанию) — для push-уведомлений.

## Шаг 1. Google Таблица и Apps Script

1. Новая Google Таблица → **Расширения → Apps Script**.
2. Удалите содержимое файла `Код.gs` по умолчанию.
3. Создайте 8 файлов (значок **+** рядом с «Файлы» → «Скрипт») с именами из папки `apps-script/`
   этого репозитория и вставьте в каждый содержимое одноимённого файла:
   `01_config.gs · 02_api.gs · 03_habits.gs · 04_achievements.gs · 05_avatar.gs · 06_notifications.gs · 07_sheets.gs · 08_ui.gs`
4. Сохраните (Ctrl+S).
5. В выпадающем списке функций выберите **`setupWorkbook`** → **Выполнить**.
6. Разрешите доступ («приложение не проверено» → «Дополнительные настройки» → «Перейти к проекту (небезопасно)»).
7. Вернитесь в таблицу — появятся 5 видимых листов (Награды, Календарь, Общая статистика,
   Графика, Профиль) и меню **«Трекер привычек»**.

## Шаг 2. Разворачивание Web App

1. В редакторе Apps Script: **Deploy → New deployment**.
2. Тип — **Web app**. Execute as: **Me**. Who has access: **Anyone**.
3. Deploy → скопируйте выданный URL вида
   `https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXXXXX/exec`.

**Важно:** после любого изменения кода `.gs`-файлов нужно создавать **новую версию
деплоя** (Deploy → Manage deployments → значок карандаша → New version) — иначе
изменения не попадут в рабочий URL.

4. В таблице: меню **«Трекер привычек» → «Показать мой токен API»** — скопируйте токен.

## Шаг 3. Фронтенд

1. Скопируйте `frontend/config.example.js` в `frontend/config.js`.
2. Впишите туда `APPS_SCRIPT_URL` и `AUTH_TOKEN` из шага 2.
3. Проверьте локально: откройте `frontend/index.html` в браузере (или через любой
   локальный статический сервер, например `npx serve frontend`).

## Шаг 4. Публикация на GitHub Pages

1. Создайте **новый** GitHub-репозиторий специально для трекера (отдельно от других
   проектов) и запушьте туда содержимое этой папки.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. Файл `.github/workflows/deploy-pages.yml` уже настроен — он соберёт `config.js` из
   секретов репозитория и опубликует `frontend/` при каждом пуше в `main`.
4. Добавьте секреты: **Settings → Secrets and variables → Actions → New repository secret**:
   - `APPS_SCRIPT_URL`
   - `AUTH_TOKEN`
   - `FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID`,
     `FIREBASE_STORAGE_BUCKET`, `FIREBASE_MESSAGING_SENDER_ID`, `FIREBASE_APP_ID`,
     `FIREBASE_VAPID_KEY` (если настраиваете push — см. Шаг 5, иначе оставьте пустыми)
5. Сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

**На телефон:** откройте этот адрес в браузере → «Добавить на главный экран».
На iOS это обязательно для работы push-уведомлений (Safari-вкладка их не получает).

## Шаг 5. Push-уведомления (Firebase, необязательно)

1. [console.firebase.google.com](https://console.firebase.google.com) → новый проект →
   план **Spark (бесплатный)**, карта не нужна.
2. **Project settings → General → Your apps → Web app (`</>`)** — зарегистрируйте
   приложение, скопируйте `firebaseConfig`.
3. **Project settings → Cloud Messaging → Web Push certificates → Generate key pair** —
   это `FIREBASE_VAPID_KEY`.
4. **Project settings → Service accounts → Generate new private key** — скачается JSON.
   В редакторе Apps Script: **Project Settings (⚙️) → Script Properties → Add script property**:
   - имя `FCM_SERVICE_ACCOUNT`, значение — содержимое скачанного JSON-файла целиком.
5. В таблице: меню **«Трекер привычек» → «Проверить FCM токен»** — должно показать успех.
6. Установите триггер напоминаний: меню **«Трекер привычек» → «Установить триггер
   напоминаний»** (запускает `checkReminders` каждые 15 минут).
7. Заполните секреты `FIREBASE_*` в GitHub (шаг 4) и `frontend/config.js` локально —
   на экране «Профиль» появится кнопка «Включить push-уведомления».

**iOS:** push работает только для PWA, добавленной на главный экран (iOS 16.4+).

## Листы таблицы

| Лист | Что показывает |
|---|---|
| Награды | Список достижений, разблокированные и в процессе |
| Календарь | Сводка по дням текущего месяца |
| Общая статистика | Агрегированная статистика для дашборда |
| Графика | Текущая стадия героя и прогресс до следующей |
| Профиль | Имя, итоги, бейджи |

Служебные листы (`_habits`, `_entries`, `_goals`, `_achievements`, `_achievement_unlocks`,
`_avatar_stages`, `_devices`, `_reminders`, `_settings`) скрыты — это источник истины,
видимые листы выше пересобираются из них автоматически после каждого действия.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Фронтенд не может достучаться до API | Проверьте `APPS_SCRIPT_URL`/`AUTH_TOKEN` в `config.js`; убедитесь что создана новая версия деплоя после правок кода |
| «unauthorized» в ответе API | Токен в `config.js` не совпадает с тем, что в Script Properties — пересоздайте через «Показать мой токен API» |
| Push не приходит | На iOS — только для PWA на главном экране; проверьте `FCM_SERVICE_ACCOUNT` и что триггер `checkReminders` установлен |
| Герой не меняется | Стадия зависит от **текущего** стрика (обнуляется при пропуске), а не рекорда — это ожидаемо |
